Advent of Code 2021
===================

My solutions for [Advent of Code 2021][aoc], written in Rust. Days 1 through 18
are solved, the rest are stubs.

Run a day with `cargo run -- --day <n>` (it defaults to today's date). Input is
fetched from the AoC site on first run and cached in `input/`, so set `SESSION`
to your AoC session cookie, or put it in a `.env` file.

[aoc]: https://adventofcode.com/2021
